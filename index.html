4. Hiệu năng / triển khai (tóm tắt paper)

  • PhoBERT-CRF tăng kích thước model chỉ ~+2MB (0.4%) so với Softmax.
  • Latency tăng ~+1.6 ms (3.8%).
  • Mục tiêu triển khai: memory ~2–4GB, latency < 50ms/câu.
